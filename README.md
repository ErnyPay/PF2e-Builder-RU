# PF2e Builder RU

Независимый русскоязычный проект-конструктор персонажей для правил PF2e.

> **Статус:** ранняя alpha. Сейчас репозиторий содержит воспроизводимый инструментарий миграции/патчинга и нашу собственную инфраструктуру проекта. Исходный APK Pathbuilder, расшифрованные базы и приватный ключ подписи **не хранятся в репозитории**.

## Что уже есть

- отдельное имя приложения: **PF2e Builder RU**;
- отдельный Android application ID: `com.pf2ebuilder.ru.builderx`;
- отдельное хранилище приложения и путь базы данных;
- отдельные provider authorities, чтобы сборка могла устанавливаться рядом с оригинальным приложением;
- собственные launcher icons и логотипы, генерируемые во время сборки;
- русифицированная/почищенная база из локальной рабочей сборки;
- безопасный DEX-патчер, который не перестраивает таблицу строк и проверяет обязательную сортировку `string_ids`;
- собственный патчер бинарного `AndroidManifest.xml`;
- v1 + APK Signature Scheme v2 подпись;
- структурная проверка всех DEX, ZIP и подписей.

## Почему в Git нет APK

Репозиторий публичный. Мы не публикуем здесь чужой APK, приватный signing key, расшифрованные upstream-базы или оригинальные проприетарные ассеты. Сборочный пайплайн принимает совместимый APK локально и применяет только наши изменения.

Это позволяет развивать собственный код и инфраструктуру открыто, не превращая репозиторий в зеркало чужого бинарника.

## Сборка

Требования:

- Python 3.11+;
- Java/JDK с `jarsigner`;
- Python-зависимости из `requirements.txt`;
- локально предоставленный совместимый base APK;
- локальный PKCS#12 signing key.

```bash
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt

export PF2E_KEYSTORE_PASSWORD='...'
python build.py \
  --base /path/to/Pathbuilder2e_256_RU_DB76_round5_polished.apk \
  --keystore /path/to/pf2e-builder-ru-signing.p12
```

По умолчанию build проверяет SHA-256 базовой сборки, чтобы случайно не применить бинарные патчи к несовместимой версии.
