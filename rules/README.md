# PF2e Builder RU rules data

Этот каталог — будущий независимый слой игровых данных проекта.

## Принципы

1. **Стабильный ID важнее отображаемого текста.** Персонажи должны ссылаться на `id`, а не на русское/английское название.
2. **Provenance обязателен.** Каждая коллекция указывает источник, лицензию/разрешение и при необходимости attribution.
3. **Не копируем upstream DB.** Данные добавляются только из источников, которые разрешено перераспространять, либо как наши оригинальные метаданные/переводы при наличии соответствующих прав.
4. **Версионируем схему.** Изменения структуры сопровождаются миграцией и тестами.
5. **Русский — first-class.** `name.ru`/`description.ru` не являются побочной DEX-подстановкой; это обычные поля наших данных.

## Структура

- `schema/catalog.schema.json` — документированная JSON Schema;
- `catalog/base.json` — пустая стартовая коллекция проекта;
- будущие `catalog/*.json` — тематические коллекции;
- `provenance` внутри каждого файла описывает происхождение и режим распространения.

CI запускает `python scripts/validate_rules.py rules/catalog` и проверяет структуру, уникальность ID и минимальные provenance-поля.
