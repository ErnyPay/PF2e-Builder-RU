# Branding

## Name

**PF2e Builder RU**

## Visual direction

The alpha identity deliberately avoids copying Pathfinder/Pathbuilder trade dress:

- dark navy background;
- mint + indigo accents;
- generic polyhedral geometry;
- `P2 / RU` monogram;
- no Paizo or Pathfinder logos.

The current assets are generated by `scripts/brand_assets.py` to keep the build reproducible.
